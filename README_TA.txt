VOICE CHANGER ANDROID - STARTER PROTOTYPE

இந்த ZIP ஒரு Android Studio project. இதில் login இல்லாத UI, நான்கு Female voice தேர்வுகள்,
phone number field, CALL / END CALL demo buttons உள்ளன.

முக்கியம்: இது இன்னும் உண்மையான call செய்யாது; microphone audio-வை மாற்றாது.
அதற்காக real-time voice conversion engine மற்றும் சட்டப்படி/வணிகரீதியாக அனுமதிக்கப்பட்ட
PSTN calling provider + backend integration தேவை. APK build செய்ய Android Studio-வில்
project திறந்து Gradle Sync செய்து Build > Build APK(s) தேர்வு செய்யவும்.

Build output பொதுவாக app/build/outputs/apk/debug/app-debug.apk.
